# Ilustrasi

Taruh file ilustrasi hero di folder ini dengan nama **`hero.png`**.

- Begitu file `hero.png` ada di sini, ilustrasi otomatis muncul di landing page
  (menggantikan tampilan emoji sementara). Tidak perlu mengubah kode.
- Format yang didukung: PNG / JPG / WEBP. Kalau pakai selain `.png`, ubah
  konstanta `HERO_SRC` di `client/src/components/HeroArt.tsx`.
- Ukuran disarankan: kotak (mis. 800x800 atau 1000x1000 px), karena slot-nya
  berbentuk persegi.

## Dari mana dapat ilustrasinya?

- Sewa ilustrator lokal (gaya kartun/komik Indonesia).
- AI image generator (Midjourney / DALL-E / dsb). Contoh prompt:
  "flat cartoon illustration, Indonesian people chaotic bureaucracy, chasing
  tax papers, bold outlines, yellow red black palette, zine style".
- Stok: Freepik / Flaticon / Vecteezy (cek lisensi).

Setelah dapat, cukup simpan sebagai `hero.png` di folder ini.
